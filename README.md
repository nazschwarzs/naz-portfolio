# Naz — Portfolio starter

A responsive, colourful portfolio starter built with HTML, CSS, JavaScript and Vite. It includes mobile navigation, scroll reveals, reduced-motion support, project cards and a GitHub Pages workflow.

## Run locally

1. Install Node.js LTS from https://nodejs.org/.
2. Open this folder in VS Code.
3. In the terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed in the terminal.

## Before publishing

- Update your name, bio, study details and experience in `index.html`.
- Replace placeholder GitHub/LinkedIn URLs and `your.email@example.com`.
- Replace project descriptions and links with real work. Do not imply that a prototype is a finished production app.
- Add your CV PDF to `public/` (create the folder) and add a link if desired.
- If your GitHub repository is named `naz-portfolio`, keep `base: '/naz-portfolio/'` in `vite.config.js`. If it is named `YOUR_USERNAME.github.io`, change it to `base: '/'`.

## Deploy to GitHub Pages

1. Create a GitHub repository named `naz-portfolio` (or your preferred name) and push this project to its `main` branch.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment → Source**, select **GitHub Actions**.
4. Push a commit to `main`, or manually run the workflow in the **Actions** tab.
5. Wait for the workflow to finish. Your site should be available at `https://YOUR_USERNAME.github.io/naz-portfolio/`.

GitHub Pages is public hosting. Do not commit secrets, private information, or API keys.
