01 / LAPTOP SERVICES

PRACTICAL SUPPORT · DEVICE CARE · SYSTEM SETUP

Affordable laptop care & support.

Part-time laptop services are available during my free time. Whether you need routine maintenance, a system setup, a hardware upgrade, or help moving your files, we can discuss the work required before arranging a service.

Prices cover labour only. Parts and licensed software are charged separately where applicable. Final availability and pricing depend on your device, compatibility, and the work required.

Cleaning & Care

Keep your laptop running smoothly

Routine maintenance can help manage heat and keep your device in good working condition.

01 Internal laptop cleaning (fan + dust)

Cleaning of internal fans and dust removal to help reduce dust build-up and overheating.

02 Thermal paste replacement

Replace old thermal paste to support heat transfer between the CPU/GPU and heatsink.

03 Cleaning + thermal paste combo

Combine internal cleaning and thermal paste replacement in one maintenance service.

Recommended every 6–12 months depending on usage and environment. Pricing may vary by laptop model and internal layout.

System Setup

Get your laptop ready for work

Operating system installation and basic software configuration for compatible devices.

01 Format laptop & install Windows 10/11

Clean Windows installation, subject to device compatibility and licence requirements.

02 Install basic software

Install requested applications, drivers, and utilities using legitimate installers.

03 Windows + basic software combo

Combine Windows setup with installation of commonly used applications.

Windows installation depends on device compatibility and a valid Windows licence. Software is installed using legitimate installers and licences.

Hardware & Data

Upgrade hardware and manage files

Assistance with compatible storage or memory upgrades and personal data transfer.

01 SSD / HDD installation or upgrade

Install or replace a solid-state drive or hard drive for additional storage or improved responsiveness.

02 RAM installation (customer-provided)

Install customer-provided memory modules after checking device compatibility.

03 Data transfer or backup

Transfer personal files between devices or help create a backup, depending on device condition and data volume.

Data transfer pricing depends on the amount of data and the condition of the source device. Please back up important files before handing over a device whenever possible.
